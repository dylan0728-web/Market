# HY 應用市場

## ⚠️ APK 上傳重要提醒

- **正式 APK 上傳區：** `market-update`
- 舊版 `1.0`：僅供備份，禁止上傳更新。
- 所有正式 APK 更新，一律使用 `market-update`。
- 請勿任意刪除正式 Release 中的既有 APK。

## 專案說明

HY 應用市場提供 Android 電視盒應用程式下載、安裝及更新。

## 主要功能

- APK 應用程式清單
- APK 下載及安裝
- 已安裝應用程式的開啟及解除安裝
- MAC 機器授權驗證
- 市場版本自動更新
- APK 版本資訊自動讀取及更新

## APK 版本管理

`market-update`
